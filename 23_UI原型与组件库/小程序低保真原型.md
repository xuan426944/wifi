# 小程序低保真 UI 原型 V3.4

## 1. WiFi 首页 - 普通客户

```
┌──────────────────────────┐
│ 门店名称：XX 咖啡        │
│ WiFi：Cafe_WiFi          │
│                          │
│   [ 一键连接 WiFi ]       │
│                          │
│ 看完广告后可获取 WiFi    │
│ [隐私政策] [用户协议]     │
│                          │
│                 ◉ 商家申请│  ← 右下角悬浮小按钮
└──────────────────────────┘
```

### 状态规则
- WiFi 已配置：显示一键连接。
- WiFi 未配置：按钮禁用，提示“门店 WiFi 暂未配置，请联系店员”。
- 广告无填充：提示“广告暂不可用，可稍后重试”，根据后台配置决定是否展示手动连接。
- 用户为普通客户：不显示商家中心。
- 用户为授权商户：右下角显示“商家中心”，同时保留“商家申请/管理入口”。

## 2. 商家申请入口

右下角悬浮按钮：

```
[商家申请]
```

点击后：
- 若未获得 openid：先静默登录。
- 若未授权手机号：进入手机号授权/手动填写页。
- 若已有 active 商户绑定：进入商家中心。
- 若已有 pending 申请：进入申请进度页。
- 若没有申请：进入申请表单。

## 3. 商家申请表单

字段：
- 申请人姓名，必填。
- 手机号，必填，可用微信手机号授权或手动填写。
- 门店名称，必填。
- 门店城市，必填。
- 门店区县，选填。
- 门店地址，必填。
- 行业，必填，下拉。
- WiFi 名称 SSID，选填。
- WiFi 密码，选填，提示“也可以审核通过后在后台配置”。
- 备注，选填。
- 同意商户协议，必选。

按钮：
- 提交申请
- 返回 WiFi 首页

## 4. 申请进度页

状态：
- draft：未提交。
- submitted：已提交，等待审核。
- reviewing：平台审核中。
- approved：已通过，显示“进入商家中心”。
- rejected：已驳回，显示驳回原因和“重新提交”。
- canceled：已取消。
