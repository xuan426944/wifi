# Phase 14 - UI Skill 验收与体验优化

## 阶段定位
本阶段不是重写业务逻辑，而是在 Phase 09、Phase 10、Phase 13 已完成页面后，统一按 `29_Skills/UI_SKILL.md` 做 UI 验收、状态补齐和体验优化。

## 输入文件
- `29_Skills/UI_SKILL.md`
- `30_UI执行策略/UI_SKILL使用策略.md`
- `23_UI原型与组件库/README_UI原型解决方案.md`
- `23_UI原型与组件库/小程序低保真原型.md`
- `23_UI原型与组件库/PC后台低保真原型.md`
- `05_小程序端/小程序页面字段级规格.md`
- `06_PC后台/后台页面字段级规格.md`
- `21_用户路径与权限路由/小程序登录后路由与权限.md`

## 开发目标
1. 检查普通客户 WiFi 首页是否足够简单。
2. 检查商家申请入口是否不干扰 WiFi 主流程。
3. 检查授权商户是否能进入商家中心并查看收益、提现、排行榜。
4. 检查普通客户是否无法访问商户页面和接口。
5. 检查后台所有表格页是否有搜索、重置、分页、加载、空状态、错误状态。
6. 检查所有高危操作是否有二次确认。
7. 检查 WiFi 密码、API 密钥、支付配置是否脱敏展示。
8. 检查收益文案是否使用预估收益、确认收益、可提现金额，禁止固定收益文案。
9. 检查财务对账页是否能展示 mock 差异。
10. 检查移动端页面是否能在常见小屏手机上正常显示。

## 禁止事项
- 不得改动已经通过测试的后端业务逻辑。
- 不得删除商户收益、提现、排行榜功能。
- 不得为了视觉效果牺牲权限校验。
- 不得引入固定收益、躺赚、拉人返利等违规文案。

## 必须输出
- UI 验收修复 commit。
- 前端页面状态补齐说明。
- 小程序客户路径截图或说明。
- 商家中心路径截图或说明。
- 后台关键页面截图或说明。
- UI 验收测试结果。

## 验收标准
- 普通客户 3 秒内知道如何连接 WiFi。
- 商家申请入口存在但不抢主按钮注意力。
- 商户收益、提现、排行榜入口清晰。
- 后台能配置商户、门店、WiFi、分成、广告、提现、排行榜、风控、第三方配置。
- 所有敏感信息默认脱敏。
- 所有高危操作二次确认。
- 所有页面都有加载、空、错误、无权限状态。
