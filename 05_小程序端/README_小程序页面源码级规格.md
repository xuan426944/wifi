# 小程序页面字段级规格 V3.4

## 总原则
普通客户觉得 WiFi 简单；授权商户能看到收益。前端隐藏不是安全边界，后端必须校验权限。

## 1. 启动与登录
流程：wx.login -> /auth/wx-login -> 保存 token 和 roleContext。
根据入口判断：
- 扫门店码：进入 WiFi 首页。
- 普通打开：普通客户进入 WiFi 最近页/扫码提示；商户可进入商家看板，但保留 WiFi 入口。

## 2. WiFi 首页（普通客户核心页）
可见角色：所有人。
字段：门店名称、WiFi 名称、广告提示、连接按钮、隐私协议入口。
按钮：一键连接 WiFi、查看手动连接、商家中心(仅 isMerchantOwner=true 显示)。
状态：
- loading: 正在获取门店信息。
- wifi_ready: 显示一键连接。
- wifi_missing: 显示“门店 WiFi 暂未配置，请联系店员”。
- ad_required: 点击后先看广告。
- ad_not_required: 直接获取连接信息。
异常：scene 无效、门店禁用、WiFi 未配置、网络错误。

## 3. 广告加载/观看页
字段：门店名、广告加载状态、倒计时可选。
逻辑：必须用户点击触发广告，不能自动弹出。
完成：res.isEnded=true 才调用 /ad/view/finish。
失败：显示重试和手动连接规则，是否允许跳过由后台配置。

## 4. WiFi 连接结果页
成功：显示已连接、返回。
失败：显示失败原因、复制 WiFi 名称、复制密码、打开系统设置指引、重试。

## 5. 手动连接页
字段：SSID、密码复制按钮、系统设置步骤。
权限：必须有有效 reward_token 或后台允许失败兜底显示。

## 6. 商家中心入口权限
如果 roleContext.canViewMerchantPages=false：不显示商家中心。
如果用户手动访问商家页面：后端 403 后跳 WiFi 首页。

## 7. 商家看板
可见角色：授权商户老板 active。
字段：今日预估收益、昨日确认收益、本月收益、累计收益、可提现金额、提现中金额、风控冻结金额、今日扫码、今日广告完成、今日连接成功、当前排名、分成比例、门店选择器。
按钮：提现、收益明细、提现记录、排行榜、门店二维码、切换门店。
状态：未绑定商户、商户待审核、商户禁用、风控冻结、无门店、无数据。

## 8. 收益明细
筛选：日期、门店、状态。
列表：日期、扫码数、广告完成、有效广告、预估收益、确认收益、状态。
说明：预估收益不等于可提现收益。

## 9. 提现页
字段：可提现金额、最低提现金额、单笔上限、日剩余额度、新商户保护期提示、有效广告完成量提示、提现金额输入。
按钮：全部提现、提交。
禁用原因：余额不足、未达门槛、风控冻结、提现关闭、保护期内、广告完成量不足。

## 10. 提现记录
字段：提现单号、金额、状态、申请时间、到账时间、失败原因。
状态文案：审核中、转账中、已到账、失败已退回、审核拒绝、异常处理中。

## 11. 排行榜
类型：今日收益、昨日收益、本月收益、累计收益、扫码人数、广告完成、连接成功、城市收益、行业收益。
显示：按后台配置 exact/range/heat/hidden。
保护：异常门店隐藏，新店参与规则由后台决定。

## 12. 门店二维码
字段：门店选择、二维码图片、下载/保存提示、张贴说明。

## 13. 我的/设置
普通客户：协议、隐私、客服、清缓存。
商户老板：商户信息、当前分成比例、协议、客服、退出登录。
