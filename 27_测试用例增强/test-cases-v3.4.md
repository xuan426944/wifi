# 测试用例增强 V3.4

## 必须测试的客户路径
1. 普通客户扫码进入 WiFi 首页，只看到 WiFi 主流程和右下角商家申请。
2. WiFi 已配置，广告完成后获取 token 并连接。
3. WiFi 未配置，不展示广告，提示联系店员。
4. 广告未完整观看，不发 token。
5. token 过期，不能获取 WiFi。
6. 连接失败，展示手动复制密码。

## 必须测试的商户路径
1. 普通用户点击商家申请，提交申请。
2. 已提交申请用户再次点击，进入申请进度页。
3. 后台审核通过后，用户进入商家中心。
4. 未授权用户访问商家中心，返回 403。
5. 商户查看收益、提现、排行榜、二维码。

## 必须测试的后台路径
1. 审核商户申请并自动创建商户、门店、老板绑定。
2. 审核时写入申请 WiFi。
3. 后台编辑 WiFi，密码加密和脱敏展示。
4. 修改全局/商户/门店分成比例，写操作日志。
5. 提现审核、mock 成功、mock 失败、重复回调。
6. 财务对账：一致、金额不一致、远端失败、本地失败远端成功。
7. 风控冻结后商户不能提现。
8. 排行榜金额展示模式 exact/range/heat/hidden。

## 权限测试
- 普通客户不能访问商家 API。
- 商户只能看自己的门店和收益。
- 运营不能修改钱包和提现配置。
- 财务不能修改广告投放和 WiFi 密码。
- 只有超管能修改分成比例和敏感配置。

## 自动化测试要求
每个 Phase 必须至少包含：
- 单元测试。
- API e2e 测试。
- 权限测试。
- Mock provider 测试。
- 关键状态机测试。
