# V3.4 不足反推与合理化设计

## 从 V3.1 反推出的不足
1. 后台页面只有菜单级描述，不足以让 Codex 完整开发表格、表单、弹窗、权限按钮。
2. OpenAPI 只有部分路径，缺请求体、响应体、错误码、幂等、分页、状态枚举。
3. 佣金比例虽有字段，但缺后台入口、接口、优先级、生效时间、日志、历史收益处理。
4. WiFi 配置虽有表和接口，但缺字段级表单、脱敏、查看权限、未配置兜底、Mock WiFi。
5. 钱包提现缺会计规则、流水枚举、冻结/解冻/冲正、并发锁、对账差异处理。
6. 小程序没有明确普通客户和授权商户的登录后路由差异。
7. 排行榜缺完整榜单类型、显示模式、刷新快照、风控剔除规则。
8. 第三方配置缺验证页面，部署后配置完成与否不清楚。
9. Codex Phase 任务偏粗，容易跳阶段或漏页面。

## V3.4 合理化设计
1. 所有页面补字段级规格。
2. 后台所有配置均可部署后手动修改，敏感密钥只走环境变量/密钥挂载，不写数据库明文。
3. 普通客户和商户老板共用小程序，但通过 role_context 路由隔离。
4. 商户收益保留，但显示为广告收益分成，严格区分 estimated/confirmed/withdrawable。
5. 平台后台强控制：分成比例、排行榜展示、广告投放、提现审核、风控规则均可配置。
6. 开发用 Mock 完成闭环，生产切 Adapter。


# V3.4 新增修正

1. 用内置低保真原型和 HTML 原型解决缺 UI 原型问题。
2. 增加商户自助入驻流程，右下角商家申请，不干扰普通客户 WiFi。
3. 广告收入真实性仍后置外部接入，不阻塞源码开发。
4. 增强广告合规提示。
5. 增强财务对账。
6. 增强测试用例。
