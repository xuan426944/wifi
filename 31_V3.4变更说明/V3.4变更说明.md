# V3.4 变更说明

## 1. V3.4 是什么
V3.4 是在 V3.3 基础上的正式集成版，核心是把 UI Skill、UI 使用时机、Phase 14 UI 验收阶段正式加入主开发包。

## 2. 相比 V3.3 的变化

### 2.1 新增 `29_Skills/UI_SKILL.md`
用于指导 Codex 开发小程序、PC 后台、HTML 原型和页面组件。

### 2.2 新增 `30_UI执行策略/UI_SKILL使用策略.md`
明确 UI Skill 什么时候用、什么时候不用，避免前期拖慢后端和核心闭环开发。

### 2.3 新增 Phase 14
用于 UI 验收和体验优化，不影响 Phase 01-08 的后端核心开发。

### 2.4 更新 Codex 主提示词
要求 Codex 在前端阶段读取 UI Skill，后端阶段不强制 UI Skill。

### 2.5 保留 V3.3 所有增强
- UI 原型
- 商户自助入驻
- 小程序广告合规提示
- 财务对账增强
- 测试用例增强
- 配置后置
- Mock + Adapter

## 3. 不变的项目主线
普通客户扫码 WiFi，观看广告后连接；商户获得广告收益分成并查看收益、提现、排行榜；平台后台管理商户、门店、WiFi、广告、收益、钱包、提现、排行榜、风控、系统配置。

## 4. V3.4 对 Codex 的最终定位
V3.4 是可用于分阶段开发的源码级 AI 开发包。Codex 应按 Phase 01-14 分阶段执行，而不是一次性开发完整系统。
