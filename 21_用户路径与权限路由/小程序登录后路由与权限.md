# 小程序登录后用户路径与权限路由

## 角色识别
小程序启动后执行 wx.login -> 后端换取 openid -> 后端返回 role_context。

role_context 字段：
- openid: 当前微信 openid
- isMerchantOwner: 是否为授权商户老板
- merchantStatus: none|pending|active|disabled|risk_frozen
- merchantId: 商户 ID，可为空
- storeCount: 可管理门店数量
- defaultLanding: wifi|merchant_dashboard
- canViewMerchantPages: boolean
- canWithdraw: boolean

## 普通客户路径
普通客户包括：未绑定商户的扫码用户、游客、普通消费者。

普通客户只能访问：
1. WiFi 首页
2. 广告加载页
3. 广告观看页
4. WiFi 连接结果页
5. 手动连接页
6. 隐私协议/用户协议
7. 错误页

普通客户不能访问：
1. 商家看板
2. 收益明细
3. 提现页
4. 提现记录
5. 商户排行榜个人收益入口
6. 门店二维码管理
7. 商户设置

访问商家页面时后端返回 403 MERCHANT_PERMISSION_REQUIRED，前端跳转 WiFi 首页并提示“当前微信未绑定商户”。

## 授权商户老板路径
授权商户老板指 merchant_owners 绑定关系 active，且 merchants.status=active。

授权商户老板可访问：
1. WiFi 首页 - 不影响自己作为客户连接 WiFi
2. 商家看板
3. 收益明细
4. 排行榜
5. 提现页
6. 提现记录
7. 门店二维码
8. 门店数据
9. 商户协议

## 双身份处理
如果一个 openid 既是客户又是商户老板：
- 扫门店码进入时，默认进入 WiFi 首页，确保客户体验简单。
- WiFi 首页右上角显示“商家中心”入口。
- 从小程序首页直接打开时，如果上次访问商家中心，可默认进入商家看板，但必须提供“返回 WiFi”入口。

## 小程序底部导航
普通客户：不显示底部商家导航，只展示单页 WiFi 流程。
授权商户：显示底部导航：WiFi、商家、排行榜、我的。

## 后端强校验
所有商家接口必须校验 openid 与 merchant_owners 绑定关系，不能只靠前端隐藏页面。


# V3.4 补充：商家申请入口

普通客户扫码后默认进入 WiFi 首页。右下角商家申请入口不影响客户连 WiFi。点击后才进入商户申请流程。授权商户扫码也默认进入 WiFi 首页，但右下角显示商家中心入口。所有商家 API 必须后端校验 merchant_owner active 状态。
